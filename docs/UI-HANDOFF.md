# ملخص المشروع لإعادة تصميم الواجهة

اعمل كمصمم واجهات ومهندس Next.js خبير. المطلوب إعادة تصميم احترافية لمشروع قائم، مع الحفاظ على الوظائف والبيانات. استخدم هذا الملخص لتقليل القراءة والتوكنز، واقرأ الكود المستهدف قبل تعديله.

## المنتج
«عقل في صندوق / Mind in a Box»: تطبيق فلسفي عربي للتأمل، محادثة شخصيات فلسفية بالذكاء الاصطناعي، حوار بين شخصيتين، مفكرة شخصية وعادات، اقتباسات، ومحتوى عضويات. يدعم العربية RTL والإنجليزية والوضعين الداكن والفاتح. مستويات العضوية: free / oracle / sanctum.

## التقنية الفعلية
جذر المشروع: C:/mindinbox-final.
المصدر الحالي: Next.js 14.2.35 App Router، React 18.3.1، TypeScript، Tailwind 3، Zustand، Framer Motion، Lucide، Firebase Auth/Firestore/Storage. التحقق الخادمي عبر jose وFirebase REST، والمدخلات عبر Zod. إعداد النشر الحالي Cloudflare Pages مع next-on-pages وwrangler.json ومسارات Edge.
تنبيه: PROJECT_MAP.md وdocs/AGENT-BRIEF.md يذكران Next 15 وOpenNext/Workers؛ هذا لا يطابق الملفات الحالية. اعتمد package.json والكود عند التعارض، ولا تغيّر منصة النشر أثناء التصميم.

## خريطة القراءة المختصرة
جميع المسارات التالية نسبة إلى جذر المشروع:
- النظام البصري: src/app/globals.css + tailwind.config.ts. متغيرات دلالية للخلفيات والأسطح والنصوص، وهوية أسود بركاني/ذهبي عتيق، ووضع فاتح بلون الورق.
- src/app/layout.tsx: مزودو الثيم واللغة والمصادقة، الخطوط، والغلاف. الخطوط: Amiri للعناوين العربية، IBM Plex Sans Arabic للواجهة، Cinzel للاتينية.
- src/components/ShellChrome.tsx + Header.tsx + Footer.tsx: التخطيط والتنقل المكتبي والمحمول. ShellChrome وحده يملك main.
- src/components/AppShell.tsx: جلسة المستخدم، التسعير والإشعارات المشتركة؛ ليس ملف التنسيق الرئيسي.
- src/lib/nav.ts + shell-config.tsx + i18n.tsx: راجع أسماء الملفات الموجودة فعلياً عند فتحها؛ تتحكم بالتنقل والغلاف واللغة.
- src/components/ViewTransitions.tsx: الانتقالات الحالية؛ تستخدم View Transitions وفولباك CSS وتحتاج مراجعة توقيت التنقل وتقليل الحركة.

## الشاشات ومكوناتها
صفحات التوجيه في src/app، والمكونات التالية داخل src/components:
- /: UtopiaHero.tsx، spatial/SpatialBox.tsx، lenses/PhilosopherLenses.tsx. واجهة دخول سينمائية واختيار شخصية وسؤال؛ حافظ على تمرير philosopher وq عبر الروابط.
- /enter: enter/EnterTemple.tsx وAuthPanel.tsx؛ الدخول والتسجيل والضيف.
- /wisdom: WisdomChat.tsx؛ دردشة الشخصية وبث الإجابة والحصة.
- /dialogue: Dialogue.tsx؛ الحوار الفلسفي.
- /journal: journal/JournalApp.tsx؛ المفكرة والعادات والملاحظات.
- /tracker: DailyTracker.tsx؛ المتابعة اليومية.
- /quotes: quotes/QuotesApp.tsx؛ الاقتباسات.
- /pricing: PricingGrid.tsx؛ /membership يحوّل إليه. /paths يشرح المسارات.
- /oracle و/sanctum: MemberLibrary.tsx؛ المحتوى المقيد بالعضوية.
- /account: AccountPanel.tsx؛ الحساب والبيانات.
- /admin: AdminConsole.tsx؛ /god-mode-admin يستخدم admin/AdminGate.tsx، وليسا مجرد مسار واحد حالياً.
- /privacy و/terms و/refund: الصفحات القانونية.
- art/ArtLayer.tsx يعرض الفن الموجود؛ لا تفحص مجلدات الصور بالجملة.

## الحدود التي يجب الحفاظ عليها
المتصفح يتصل بـ /api/ai و/api/dialogue للبث. المصادقة في src/lib/auth، والمزامنة في src/lib/session.ts وfirebase.ts وjournal/store.ts وconversations.ts. الصلاحيات والحصص يقررها الخادم؛ لا تستبدلها بأعلام محلية. لا تعدّل APIs أو قواعد Firebase أو منطق تسجيل الدخول ضمن إعادة التصميم. حافظ على ترقية حساب الضيف بنفس UID، والمحتوى المحلي، وحالات البث والإلغاء والأخطاء. لا تستخدم innerHTML لردود الذكاء الاصطناعي. احتفظ بسياسة CSP والـ nonce، وبـ main واحد، وإمكانية لوحة المفاتيح.

## المطلوب بصرياً
طوّر هوية فلسفية هادئة ومميزة: هرمية واضحة للعناوين، مسافات متسقة، أسطح مقروءة، ومكونات موحدة. أعط الأولوية لتباين النصوص في الوضعين، أحجام اللمس، وتنقل الهاتف، ثم الرئيسية والدردشة والمفكرة وبقية الصفحات. لا تعالج التباين بإضافة طبقات شفافية عشوائية، ولا تعتمد قالب بطاقات متكرر لكل المحتوى. حرّك الكلمات العربية كاملة، واحترم prefers-reduced-motion. أرقام AUDIT-UI.md تاريخية وليست قياساً للحالة الحالية.

## طريقة العمل الاقتصادية
ابدأ بملفات النظام البصري والغلاف والرئيسية فقط، ثم افتح الملفات المطلوبة للشاشة التالية. لا تقرأ node_modules أو lockfile أو الاختبارات أو public/art أو assets-source بالجملة. لا تطلب إعادة شرح المشروع. قدّم تصوراً موجزاً ثم نفّذ على مراحل قابلة للمراجعة. لا تضف مكتبات أو تغيّر الإصدارات دون ضرورة. اختبر العربية والإنجليزية والوضعين عند 360 و390 و768 و1440px، ثم typecheck وlint وbuild واختبارات السلوك المتأثر. لا تدّعِ اختبار المتصفح إن لم تنفذه.

## حالة العمل عند التسليم
توجد تعديلات غير ملتزم بها تخص المرحلة الأولى الأمنية. آخر تشغيل لاختبارات الوحدة نجح: 419 اختباراً، لكنه سبق بعض التعديلات اللاحقة. اختبارات قواعد Firebase كشفت إخفاقات ويجري إصلاحها؛ لم يُعَد تشغيلها بعد آخر تعديل، ولم يُعتمد بناء نهائي. افحص git diff أولاً، ولا تمحُ هذه التعديلات أو تصفها بأنها مكتملة. نطاق مهمتك الجديدة هو الواجهة؛ أبقِ تغييرات الأمان منفصلة عنها.
